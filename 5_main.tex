\begin{abstract}
    \noindent
    In this work, I have explored the use of machine learning and explainability methods in the context of colon-cancer tissue health assessment using fourier transform infrared spectroscopy over the spectral range $1000$-$1800$ cm$^{-1}$. For this, I implemented mean squared error (MSE), cosine similarity, principal component analysis (PCA) informed linear discriminant analysis (LDA), PCA informed extreme gradient boosting (XGB), standard XGB and ensemble scale-invariant convolutional neural network (SCNN) methods. Each of these were used for the classification of colon cancer samples as non-cancerous, hyperplastic, adenomatous, or cancerous. The SCNN method was found to be the most effective, achieving a weighted overall accuracy of  $58.7\pm3.7\%$ when performing four-class classification on a four-fold cross-validated test set. When mapped to binary classification, the SCNN also performed best and performed non-cancer vs cancer classification with an overall weighted accuracy of $83.2\pm5.9\%$. The explainability of this model was then explored using the context-representative interpretable model explanation (CRIME) framework. This was capable of extracting multiple contexts to explain each tissue classification. The spectra and weightings associated with these contexts were then used to create a weighted cosine similarity classification model (LCRIME). The best of these LCRIME models for four-class classification utilised a $20\%$ supervised convolutional encoder - transformer decoder variational autoencoder (VAE). This model was capable of reproducing SCNN classification predictions with an overall weighted accuracy of $47.5\pm7.6\%$. For binary classification, the best LCRIME model utilised a $20\%$ supervised transformer encoder-transformer decoder VAE and achieved an overall weighted accuracy of $74.7\pm 10.9\%$ on the same test set.
\end{abstract}
