\section{Theory and Methods}
\subsection{FTIR Spectroscopy}
%Check which of the CHARM methods are actually needed here and potentially don't bother with them all

Infrared (IR) spectroscopy works by directing a broadband spectrum with wavenumbers ranging from around $400-4000 \text{ cm}^{-1}$ (for mid-IR spectroscopy) \cite{su_fourier_2020} onto a sample. This coherent spectrum then excites resonant vibrational modes within molecular bonds inside the sample, causing absorption of specific frequencies depending on the composition of the incident sample. This decreases the intensity at the absorbed frequencies relative to the broadband baseline, generating a characteristic spectrum for each vibrational mode. The frequencies at which these vibrations occur are ultimately determined by quantum electron density effects \cite{atkins_atkins_2022}. However, they are often well modelled by a simple harmonic oscillator approach \cite{lin_calculating_2008,berthomieu_fourier_2009} subject to the requirement that the molecular dipole moment $\mu$ can change \cite{gong_application_2024,veit_predicting_2020}. For the bond demonstrated in Figure \ref{fig:ir_bond}, we therefore expect IR absorption at frequency:
\begin{equation}
    \nu = \frac{1}{2\pi c} \sqrt{\frac{k(m_1+m_2)}{m_1 m_2}}.
\end{equation}
The requirement for molecules to be polar results in FTIR being particularly sensitive to functional groups with high electronegativity differences like those depicted in Figure \ref{fig:ir_bond}. \\

  \label{fig:ir_bond}
\end{figure}

\noindent
Modern devices use a Fourier transform-based (FTIR) interferogram approach \cite{griffiths_fourier_1983}, enabling high signal-to-noise (SNR) ratios to be achieved. FTIR can detect biochemical features including nucleic acids, proteins, lipids, and carbohydrates within biological samples by matching the observed spectra with known forms for different bonding types, functional groups and intermolecular interactions \cite{su_fourier_2020}. Typical absorption groups within biological samples are detailed in Table \ref{table:functional_groups}. Furthermore, we expect FTIR to be a good for cancer detection, as cancerous growth is often associated with changes in the acidity of tissues, and changes in acidity are known to cause hydrogen-bonding induced changes to FTIR spectral peak positions \cite{wolpert_infrared_2006,torii_modeling_2024,czowski_cancer_2020}. This effect is demonstrated in Figure \ref{fig:ir_differences_ph}.

\subsubsection{FTIR Dataset Collection}
\label{sec:mdethods:data_collection}
The dataset used in this work contains FTIR spectral images of 90 colon cancer tissue samples originally collected for the MINERVA project \cite{noauthor_minerva_nodate}. These images were produced by collaborators at the University of Exeter using an Agilent 620 FTIR microscope, an Agilent 670 FTIR spectrometer with a Globar light source, and a liquid-nitrogen cooled 128x128 focal plane array detector \cite{nallala_high-resolution_2016}. The spectral images produced by this process were then separated into stroma and non-stroma regions using $K$-means clustering methods and processed to remove paraffin spectral features as explained in \cite{nallala_high-resolution_2016,mathieson_why_2020}. This work mostly focusses on the use of individual pixels within these spectral images for classification tasks. Each pixel contains FTIR absorption intensity data at $801$ wavenumbers from $1000$ cm$^{-1}$ to $1800$ cm$^{-1}$.

\subsection{Cross-Validation Approach}
\label{sec:methods:data_split}
FTIR data was produced for 90 samples, of which 31 were classified as normal, 17 as hyperplastic, 27 as adenomatous, and 15 as cancerous. Due to the desire to accurately predict performance in four-category prediction tasks, a 4-fold cross-validation approach was adopted \cite{kohavi_study_2001}. This involved splitting the dataset into four parts using the stratified group K-fold method, which produces splits subject to the constraints of both preserving the proportion of samples (pixels) for each class within each split to the maximum extent possible whilst also enforcing the requirement for non-overlapping groups (images) between splits \cite{t_r_stratified_2023,gunopulos_stratification_2011, szymanski_network_2017}. When training ML models on spectral data, an approach was adopted where for each set of four folds, two were used for training, one for validation and one for testing. For methods which did not require validation or hyperparameter tuning, the validation set was discarded, enabling maximal comparability between methods.

\subsection{Baseline Classification Methods}
\label{sec:methods:baseline_classification}
The most intuitive approach for classifying spectra according to their severity is to calculate the mean spectrum for each classification within the training set and then to measure which mean spectrum most closely resembles a test spectrum. Similar to work by Villazon et al. \cite{villazon_cancer_2025}, this work implements a mean square error (MSE) method, and a cosine similarity method. The mean square error is defined as:
\begin{equation}
    \text{MSE}(\vec x,\vec y) = \frac{1}{n} \sum_{i=1}^{n} (x_i - y_i)^2
\end{equation}
where $\vec x$ and $\vec y$ are the spectra being compared, and $n$ is the number of wavenumbers (dimensions) in each spectrum. The cosine similarity is also defined as:
\begin{equation}
    \text{Cosine Similarity}(\vec x, \vec y) = \frac{\vec x \cdot \vec y}{|\vec x| |\vec y|},
\end{equation}
which produces values between $-1$ and $1$, respectively denoting complete orthogonality and similarity between the two spectra. The classification of each test spectrum is then set as that which corresponds to the mean spectrum which minimises the MSE or maximises the cosine similarity.

\subsection{Machine Learning (ML) For Classification}
\label{sec:methods:trad_ML_methods}
Throughout this work, I use three standardised machine learning processes for FTIR spectral classification, two of which utilise principal component analysis (PCA) (see \ref{sec:methods:pca}) to reduce input data from 801 to 25 dimension. The methods implemented are PCA with linear discriminant analysis (LDA) \cite{fisher_use_1936,ghojogh_linear_2019}, PCA with extreme gradient boosting (XGBoost or XGB) \cite{chen_xgboost_2016}, and XGBoost applied directly to the 801 dimensional input data. Unless otherwise stated, the hyperparameters used for these methods take their default values as specified in the scikit-learn \cite{pedregosa_scikit-learn_2011} and XGBoost \cite{chen_xgboost_2016} libraries. A theoretical overview of these methods is also included in Appendix \ref{appendix:ML_methods}. \\ 

\subsection{Neural Networks}
Neural networks \cite{schmidhuber_deep_2015,goodfellow_deep_2016,lussier_deep_2020} are machine learning algorithms built from layers of connected nodes (neurons) acted on by activation functions (§\ref{appendix:activations}). The weights and biases associated with each neuron are then learnt using backpropagation \cite{rumelhart_learning_1986} and gradient descent \cite{ruder_overview_2017} to minimise a loss function. This finds a mapping from inputs to outputs. With suitable model design, regularisation \cite{goodfellow_deep_2016,kukacka_regularization_2017} and hyperparameter selection, these mappings can be tuned to generalise well to unseen data. Throughout this work, neural networks are trained, validated and tested on independent folds of data as described in §\ref{sec:methods:data_split}, the Adam optimiser \cite{kingma_adam_2017} is used for gradient descent, and hyperparameter tuning is conducted on the validation split using the Weights and Biases tool \cite{biewald_experiment_2020}. A full overview on the different neural network layer types is included in Appendix \ref{appendix:ML_methods}, and a brief overview is included in Figure \ref{fig:connection_methods}.\\

\subsubsection{A Scale-Adjusting Convolutional Neural Network (SCNN)}
\label{sec:methods:scnn}

In this work, a SCNN similar to that presented by Zaki et al. \cite{zaki_explainable_2024} is implemented for feature extraction from 801 dimensional FTIR spectra. The model architecture is summarised in Figure \ref{fig:scnn_arch}. Notable features include the use of three scanning convolutional heads to extract information at different spectral scales, which is important for capturing the variable-width peaks in FTIR spectra. Furthermore, the use of $\tanh$ followed by ReLU activation functions reduces the effect of unphysically large convolutional outputs, which could otherwise produce exploding gradients \cite{song_fine-grained_nodate,li_learning_2020,zaki_explainable_2024}. Finally, the last layers in the network learn a three parameter logistic output \cite{yu_three-parameter_2021};
\begin{equation} %Px = c+(1-c)/(1+torch.exp(-a*(x-b)))
    \boldsymbol{\hat y} = c+ \frac{(1-c)}{1+\exp(-a(\boldsymbol{x}-b))},
\end{equation}
where $c$ is a guess parameter, $b$ denotes difficulty and $a$ denotes the discrimination. This allows the model to find a baseline offset for categorisation probability corresponding to the how it could sometimes be impossible to distinguish between classes using only FTIR data.

\subsection{Explainability}
\subsubsection{Local Interpretable Model-Agnostic Explanations (LIME)}
LIME \cite{ribeiro_why_2016} is a model-agnostic explainability technique which works by producing $N$ perturbations around an input vector, $\boldsymbol{x}$ and observing how perturbing different features alters classification probabilities. In this work, a variant of this is employed where each of the $d$ input features (wavelength intensities) are one-hot encoded \cite{samuels_one-hot_2024} into a vector, $\boldsymbol{x'}$ of length 10, with the encoded value corresponding to the training-set decile in which that feature value lies. Perturbed samples, $\boldsymbol{z'}$, are then generated by considering each feature, either retaining their one-hot encoding with probability $1/2$, or uniformly allocating a new one-hot encoding, also with probability $1/2$. A numeric vector $\boldsymbol{z}$ is then generated by randomly sampling within the deciles associated with each value in $\boldsymbol{z'}$. We then aim to train a local linear model $g\in \mathcal G$ to approximate the behaviour of the original model we wish to explain, $f$, around $\boldsymbol{x}$. Here, $\mathcal G$ is a class of potentially interpretable models. The selected LIME explanation is then given by:
\begin{equation}
    \xi(x)=\underset{g\in \mathcal G}{\text{argmin}} \left[ \mathcal L(f,g,\pi_x)+\Omega(g)\right],
    \label{eq:explanation}
\end{equation}
where the locality-aware loss $\mathcal L(f,g,\pi_x)$ encodes the faithfulness of $g$ to $f$ in the locality $\pi_x$ and $\Omega(g)$ is an explanation-complexity penality term. This process is illustrated in Figure \ref{fig:lime_illustration}. In this work we are considering classification tasks, so the locality-aware loss is calculated using a square loss between the predicted probability for positive classification as given by $f$ and $g$ (the LIME process is repeated for each class). This takes the form:
\begin{equation}
    \mathcal L(f,g,\pi_x)=\sum_{z, z'}\pi_x(z)\left(f(z)-g(z')\right)^2,
\end{equation}
where $\pi_x(z)=\exp(-D(x,z)^2/\sigma^2)$ encodes locality through an $L_2$ \cite{shan_targeted_2019,ribeiro_why_2016, why} distance function $D$ and $\sigma$ is generally set as the median of all $D$ values. We then solve \ref{eq:explanation} using a ridge regressor over $N$ perturbed samples for each sample to be explained, giving \cite{ribeiro_why_2016}: 
\begin{equation}
    (\boldsymbol{w},\boldsymbol{b}) = \underset{\boldsymbol{w}, \boldsymbol{b}}{\text{argmin}} \sum_{\boldsymbol{z}, \boldsymbol{z'}} \pi_x(\boldsymbol{z})\left[f(\boldsymbol{z})-\left(\boldsymbol{w}^T \boldsymbol{z'}+\boldsymbol{b}\right)\right]^2+\lambda |\boldsymbol{w}|^2_2,
\end{equation}
where the weights $\boldsymbol{w}\in\mathbb{R}^{dx10}$ and biases $\boldsymbol{b}\in \mathbb{R}^d$ are those of the linear model $g$ for a single class in a single sample. Calculating the $L_2$ norm of the $10$ weights for each feature then produces relative importance scores for each feature within class $k$, $\boldsymbol s_k$. Finally, the total importance score for each feature is calculated by performing a probability-weighted sum over all classes \cite{ribeiro_marcotcrlime_2025}: 
\begin{equation}
    \boldsymbol{s} = \sum_k p_k(\boldsymbol x) \boldsymbol s_k.
\end{equation}
An example of the LIME weightings this process produces is shown in Figure \ref{fig:lime_weights_example}.

\subsubsection{Context Representative Interpretable Model-Agnostic Explanations (CRIME)}
\label{sec:methods:crime}
The CRIME method \cite{zaki_explainable_2024} aims to expand on LIME by finding contexts which have similar classification explanations. This is achieved by passing the LIME results through a variational autoencoder (VAE) \cite{kingma_auto-encoding_2022,kingma_semi-supervised_2014} to learn a low-dimensional latent space representation of the explanations. This latent space is then clustered into $K$ contexts using $K$-means clustering \cite{jin_k-means_2011}, each of which can then be investigated further.

Here, I expand on this work by investigating the use of different VAE architectures as described in §\ref{sec:methods:vae}, and by using the clusters themselves to perform explainable linear classification.

\subsubsection{Variational Autoencoders (VAE)}
\label{sec:vae}

Attempting to find clusters of the explanations produced by LIME can be viewed as either an unsupervised learning problem - clustering the LIME spectra with no additional information, or as a semi-supervised learning problem, where known training labels are used to inform latent space construction. In this work, I implemented both approaches by implementing VAEs, which attempt to learn a generative model with parameters $\theta$ to enable mapping from the data $\boldsymbol{x}$ to a latent representation $\boldsymbol{z}$ and back again - illustrated in Figure \ref{fig:VAE}. A theoretical overview of VAEs is included in Appendix \ref{appendix:VAE_derivation}, and shows that an unsupervised VAE is optimised by minimising the negative evidence lower bound (ELBO):
\begin{equation}
    \mathcal L(\boldsymbol{x}) = -\frac{1}{2}\text{MSE}(\boldsymbol{x}, \boldsymbol{y}_\mu)+\beta \frac{1}{2}\left[1+\log(\boldsymbol{\sigma}^2)-\boldsymbol{\mu}^2-\boldsymbol{\sigma}^2\right],
    \label{eq:elbo}
\end{equation}
where $\boldsymbol{y}_\mu$ is the output of the decoder, $\beta$ is a hyperparameter controlling the relative weighting of the reconstruction loss and KL divergence terms \cite{higgins_beta-vae_2017}, and $\boldsymbol{\mu}$ and $\boldsymbol{\sigma}^2$ are the latent space mean and variance projections respectively.

  \label{fig:VAE}

\noindent
 When using a semi-supervised VAE approach, we follow the M2 method described by Kingma et al. \cite{kingma_semi-supervised_2014}, so modify (\ref{eq:elbo}) to include a classification cross-entropy loss \cite{kingma_semi-supervised_2014,mao_cross-entropy_2023} assessing the difference between predicted and true class probabilities. These predicted class probabilities are given by softmax over the output from a two-layer ($64\rightarrow128\rightarrow4$ node) fully-connected layer at the end of the VAE encoder, prior to $\mu$ and $\sigma$ projection. The implementations of these ELBOs and the reparametrisation trick can be found in §\ref{sec:code:ELBOs} and §\ref{sec:code:reparam} respectively. The VAE architectures used in this work are summarised in Table \ref{tab:ssvae_arch}. Furthermore, because each VAE is already implicitly using a model trained on the training set for each split, the VAE itself is trained on the LIME explanations of the validation set.

\subsubsection{CRIME with Linear Classification}
\label{sec:crime_linear}
Once the CRIME method has been used to cluster the LIME explanations into contexts, the mean FTIR spectrum associated with the LIME explanations in each context can be found. This work then uses these mean spectra, along with the mean LIME weights for each context to produce an explainable linear classification model. This is achieved by first classifying each context according to the most common classification (normal, hyperplastic, adenoma, or cancer) of the spectra which are placed into the context when training the VAE on the validation set. We then compute a LIME-importance-weighted cosine similarity between each mean cluster spectrum and a test spectrum. The method used to calculate this similarity was initially developed by Zaki et al. to calculate the similarity of their clustered spectra to known indicator spectra \cite{zaki_explainable_2024}. For each clustered spectrum, $\boldsymbol{\mu}$, with weights $\boldsymbol{w}$, we scale both to a range $[-1,1]$ according to the minimum and maximum values within each vector, giving scaled vectors $\hat{\boldsymbol{\mu}}$ and $\hat{\boldsymbol{w}}$. We then do the same for a test spectrum $\boldsymbol{t}\rightarrow \hat{\boldsymbol{t}}$. The cosine similarity is then calculated as:
\begin{equation}
    \text{sim}=\frac{\hat{\boldsymbol{t}}^T (\hat{\boldsymbol{\mu}} \cdot \hat{\boldsymbol{w}})}{|\hat{\boldsymbol{t}}|^2 |\hat{\boldsymbol{\mu}} \cdot \hat{\boldsymbol{w}}|^2}.
\end{equation}
Each test set spectrum is then classified according to the context with which is achieves the highest similarity score. The respective context classification is then used to map the test spectra to a physical classification (normal, hyperplastic, adenoma or cancer). Due to the low number of independent samples, it is not possible to further divide the dataset to find a reliable validation set for this method, so sensible VAE parameters are selected based on their performance classifying the validation set before performing a final run to evaluate performance on the test set.

\subsection{Evaluation Metrics}
The dataset used in this work is highly imbalanced, so a very high accuracy can be achieved by simply predicting the most common class. To avoid this, I calculated performance metrics relative to each "true" classification, $k$, using the following confusion matrix $(\mathrm{CM})$ (see Figure \ref{fig:confusion_matrix}) conventions:
\begin{align}
\text{TP}_k &= \mathrm{CM}_{kk}, &
\text{FN}_k &= \sum_j \mathrm{CM}_{kj} - \text{TP}_k, \\
\text{FP}_k &= \sum_i \mathrm{CM}_{ik} - \text{TP}_k, &
\text{TN}_k &= \sum_{i,j} \mathrm{CM}_{ij} - \bigl(\text{TP}_k+\text{FN}_k+\text{FP}_k\bigr).
\end{align}

\noindent From these counts we then define:
\begin{align}
\text{Sensitivity}_k &= \frac{\text{TP}_k}{\text{TP}_k+\text{FN}_k}, &
\text{Specificity}_k &= \frac{\text{TN}_k}{\text{TN}_k+\text{FP}_k}, \\[4pt]
\text{Accuracy}_k   &= \frac{\text{TP}_k+\text{TN}_k}
                            {\text{TP}_k+\text{TN}_k+\text{FP}_k+\text{FN}_k}, &
\text{FPR}_k        &= \frac{\text{FP}_k}{\text{FP}_k+\text{TN}_k}.
\end{align}

\noindent Furthermore, to fairly measure performance despite dataset imbalance, we define the overall weighted accuracy (OWA) as: 
\begin{align}
\text{Overall Weighted Accuracy} &= \frac{\sum_{k=0}^{K} w_k \cdot \text{Accuracy}_k}{\sum_{k=0}^{K} w_k}, \\ \text{where} \quad w_k &= \frac{\text{True number of samples in class } k}{\text{Total number of samples}}.
\label{eq:overall_accuracy}
\end{align}

\subsubsection{Binary Classification Methodology}
\label{sec:methods:binary}
Due to the high computational cost in training the SCNN networks, it was decided that binary classification performance results throughout this work would be calculated using four-class classification predictions. For this, we categorise cancer, hyperplastic and adenomatous predictions as non-cancerous and cancerous predictions are unchanged.
