\section{Conclusions}
In this work, I have explored the use of mean squared error (MSE), cosine similarity, principal component analysis (PCA) informed linear discriminant analysis (LDA), PCA informed extreme gradient boosting (XGB), standard XGB and ensemble scale-invariant convolutional neural network (SCNN) methods for the classification of colon cancer samples as non-cancerous, hyperplastic, adenomatous, or cancerous via the analysis of FTIR spectral data. The SCNN method was found to be the most effective, achieving a weighted overall accuracy of  $58.7\pm3.7\%$ when performing four-class classification of on a four-fold cross-validated test set. When mapped to binary classification, the SCNN also performs best and achieves non-cancer vs cancer classification with an overall weighted accuracy of $83.2\pm5.9\%$. The explainability of this model was then explored using the context-representative interpretable model explanation (CRIME) technique. This was capable of extracting multiple contexts to explain each tissue classification. The spectra and weightings associated with these contexts were then used to create a weighted cosine similarity classification model (LCRIME). The best of these LCRIME models for 4-class classification utilised a $20\%$ supervised convolutional encoder - transformer decoder VAE. This model was capable of reproducing SCNN predictions with an overall weighted accuracy of $47.5\pm7.6\%$ on the four-fold cross-validated test set. For binary classification, the best LCRIME model utilised a $20\%$ supervised transformer encoder-transformer decoder VAE and achieved an overall weighted accuracy of $74.7\pm 10.9\%$ on the same test set.\\ 

\noindent
Future works could try to improve the performance of the classification models by implementing ordinal regressive losses \cite{} during SCNN training, implementing transformer networks directly for classification, or  exploring the use of different weak learner ensemble methods instead of simple voting. Furthermore, the explainability work could be expanded on by utilising different dataset folds to achieve finer hyperparameter tuning for the CRIME VAEs, and by exploring the use of other explainability methods like SHAP \cite{}.
