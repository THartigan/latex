\section{Full Context Classification Results}

The full results for binary and four-class classification tasks using context explained spectra as described in \ref{sec:methods:context_matching} are presented below. Within both tables, the method denotes which VAE was used to produce the context-based classification model - CP denotes a convolutional encoder and MLP decoder; CT denotes a convolutional encoder and transformer decoder; and DT denotes a transformer encoder and transformer decoder. The value after the two characters denotes the supervision level; 0.2 $\implies$ 20\% supervision. The comparison column denotes which outputs are compared. For example Context-Model compares the Context classification predictions to the SCNN Model predictions and Context-Label compares the context classification predictions to the original dataset labels. The SCNN Model-Label predictions are included in the final row of both tables for comparison.
