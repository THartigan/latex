\section{Full Classification Results}
The full results for performance in four-class and binary classification tasks are presented below. Tables \ref{tab:quad_results_full} and \ref{tab:binary_results_full} show the results when using traditional ML methods and when using the ensemble SCNN method developed in this work. Tables \ref{tab:quad_results_full_context} and \ref{tab:quad_results_full_context} show the results when using difference VAE architectures to generate context-based classification models. All results are generated using four-fold cross-validation as described in §\ref{sec:methods:data_split}. Within these latter two tables, the method denotes which VAE was used to produce the context-based classification model. CP denotes a convolutional encoder and MLP decoder; CT denotes a convolutional encoder and transformer decoder; and DT denotes a transformer encoder and transformer decoder. The value after the two following digits denotes the supervision level; 0.2 $\implies$ 20\% supervision. The comparison column denotes which outputs are compared. For example Context-Model compares the Context classification predictions to the SCNN Model predictions and Context-Label compares the context classification predictions to the original dataset labels. In each case, we assume the latter metric is truthful. The SCNN Model-Label predictions are included in the final row of both tables for comparison.
